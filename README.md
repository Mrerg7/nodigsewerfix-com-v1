# nodigsewerfix.com

Premium domain acquisition landing page for **nodigsewerfix.com** — built with Astro static output and deployed to Cloudflare Workers Static Assets.

## Stack

- Astro 5 (static output, no adapter)
- TypeScript + Tailwind CSS
- Content Collections (benefits, facts, ideal-for, FAQ)
- Cloudflare Images CDN
- Structured data (JSON-LD) + full Open Graph meta
- Sitemap + robots.txt

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run deploy
```

Deploys the `dist/` folder via `wrangler.toml` Workers Static Assets configuration.
